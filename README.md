# Squires Kit

A free, open-source kit that helps Claude Code set up a workspace around your work.

## Get started

1. Download `squires-kit.zip` at https://squiresdesk.com.
2. Drag the zip into Claude Code and say: **Install this kit.**
3. Run **/squires-kit** or ask Claude to start Squires setup. Choose personal work or business work, pick a new workspace folder, and answer the interview in your own words.

If your app does not accept a zip, unzip it, open the extracted folder locally in Claude Code, and ask it to read SKILL.md and install the kit. It will guide you into a separate workspace before starting the interview. Do not install over an existing project.

Manual skill installation: put this complete directory at `~/.claude/skills/squires-kit/`. Start a new Claude Code session and run `/squires-kit`. See https://code.claude.com/docs/en/skills for current host instructions.

## Source

Public repository: https://github.com/sammadura/squires-kit

## What is included

- SKILL.md: installation and workspace setup instructions.
- templates/personal.md: the complete personal-work setup guide.
- templates/business.md: the complete business setup guide.
- LICENSE: the MIT license.

The templates contain a guided interview, workspace templates, memory and task routing, reusable procedures, connection guidance, unfinished-work records, and rules for reviewing and archiving information. The kit supplies instructions; the AI app supplies the model, file access, and tools. Outcomes depend on the host, permissions, and services you connect.

The files are the source. Read, edit, share, fork, or use them commercially under the MIT license. Keep the copyright and license notice with copies. Your workspace and personal data remain yours. Never contribute private records or credentials.

## Cost

The kit is free. Claude Code and connected services may cost money separately. Personal implementation with Sam is a separate, optional paid service at https://squiresdesk.com/checkout/sam.

## Privacy

The kit has no license-server calls, tracking, or activation requirement. Your AI provider and connected services process data according to their own terms. Website email signup is separate from the kit's operation.

## Updates

Review updates before applying them. Do not replace the generated CLAUDE.md in an existing workspace with a fresh bootstrap: that would restart setup. Keep a backup of your workspace first.
